# Assets

- `map/world.bin`: country borders from [Natural Earth](https://www.naturalearthdata.com/) 1:50m, public domain, built by
  `scripts/gen-world.py`.
- `map/cities.tsv`: cities of at least 15,000 people from [GeoNames](https://www.geonames.org/), CC BY 4.0, built by
  `scripts/gen-cities.py`.
- `tray/*.svgfrag`: digit, minus and arrow paths from [Tabler Icons](https://tabler.io/icons) 3.49.0, MIT License,
  Copyright (c) 2020-2024 Paweł Kuna.
